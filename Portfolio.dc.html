03
Garage Manage Full-stack vehicle maintenance app
Node.js · PostgreSQL {{ sign3 }}

Problem

My dad wanted an easier way to track our family's vehicles. Remembering each car's maintenance history, upcoming services and expiration dates was always hard.

What I did

Vehicle registration, maintenance history with dates, costs and locations, expiration management, a dashboard of upcoming reminders, email reminders, and document uploads. The hardest part was authentication and sessions — keeping each user logged in and their data isolated.

Outcome

Learned to integrate a full backend into a real app instead of only building the frontend, plus a lot about authentication and user management.

04
Forge Gym Gym App - FlyRankAi Capstone
React.js · Next.js {{ sign4 }}

Problem

As part of the selection process for the FlyrankAI internship, I needed to build a production-ready project that solved a real-world problem while demonstrating mandatory AI integration, effective API management, and clean frontend architecture.

What I did

I independently designed and developed a fitness web app powered by an LLM using Next.js, React, TypeScript, and Tailwind CSS. I integrated the Groq API alongside the Vercel AI SDK to stream real-time personalized workout routines, nutrition plans, and caloric targets. Additionally, I implemented unit testing using Vitest to ensure UI component reliability.

Outcome

Mastered AI SDK integrations, streaming responses, and prompt handling in a modern Next.js environment. Successfully delivered a fully tested, end-to-end frontend project that elevated my portfolio for the FlyrankAI selection process.
